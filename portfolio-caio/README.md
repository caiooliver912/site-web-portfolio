# 🛡️ Site Web de Portfólio

Portfólio pessoal desenvolvido com **HTML5**, **CSS3** e **JavaScript** puro, sem frameworks ou dependências externas. O site é uma apresentação sobre mim como um apaixonado por cibersegurança, principalmente pela área 
de Blue Team

## 📄 Páginas

- **Início** (`index.html`) — apresentação inicial sobre mim, quais são meus interesses dentro de cibersegurança, terminal linux animado.
- **Sobre** (`pages/sobre.html`) — trajetória, características, plataformas de estudo, habilidades e formação acadêmica.
- **Contato** (`pages/contato.html`) — formulário de contato com validação e links para redes sociais.

## 📁 Estrutura do projeto

```
.
├── index.html            # Página inicial
├── pages/
│   ├── sobre.html        # Página sobre/biografia
│   └── contato.html      # Página de contato
├── css/
│   └── style.css         # CSS para a estilização 
├── js/
│   └── main.js           # JavaScript do site responsável pela interatividade (terminal, menu, formulário)
├── img/
│   └── perfil.jpg        # Minha foto que aparece na página de Sobre
└── README.md             # Este arquivo
```

## ⚙️ Recursos JavaScript

- **Terminal animado** — simulação de terminal Linux com digitação de comandos.
- **Validação de formulário** — verificação de campos obrigatórios e formato de e-mail em tempo real.
- **Ano dinâmico** — atualização dinâmica do ano no footer das 3 páginas

## 🖥️ Tecnologias utilizadas

- HTML5 semântico com atributos de acessibilidade
- CSS3 com Flexbox, Grid Layout e Custom Properties
- JavaScript puro
- Google Fonts — IBM Plex Sans e IBM Plex Mono

## 📝 Observações

- O formulário de contato é somente front-end. Adicionarei um tratamento e recebimento de mensagens futuramente
- O site é totalmente estático e pode ser aberto diretamente no navegador via `index.html`.
